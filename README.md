# 牧会手帳 (notion-pastor-app)

牧師の日々の働きを支える、Notion連携の多機能モバイルアプリ。

- **説教・礼拝準備** — 説教のタイトル・聖書箇所・主題・アウトラインを管理
- **教会員・牧会管理** — 教会員名簿と、一人ひとりへの訪問・電話などの牧会記録（次回フォロー予定つき）
- **行事・スケジュール管理** — 礼拝・祈祷会・結婚式・葬儀などの予定と奉仕者
- **祈祷課題・献金記録** — 祈祷課題の管理と、献金の簡易記録

すべてのデータは自分のNotionワークスペースに保存されます（サーバーなし、トークンは端末内にのみ保存）。

## 技術構成

- Expo (managed) + React Native + TypeScript + expo-router
- Notion API を `fetch` で直接呼び出す自前クライアント（`src/lib/notion.ts`）
- `expo-secure-store` でトークン・データベースIDを端末に保存
- `@tanstack/react-query` でデータ取得・更新・キャッシュを管理

## セットアップ

### 1. アプリを起動する

```bash
npm install
npx expo start
```

- **実機で試す**: スマホに [Expo Go](https://expo.dev/go) アプリをインストールし、ターミナルに表示されるQRコードを読み取る
- **ブラウザで試す**: `npx expo start --web` または起動後に `w` キー

このMacにはXcodeが入っていないため、iOSシミュレータでの起動はできません。実機 + Expo Go での確認を推奨します。

### 2. Notionと連携する

アプリを開くと連携セットアップ画面が表示されます。

1. [notion.so/my-integrations](https://www.notion.so/my-integrations) で新しいインテグレーションを作成し、Internal Integration Secret をコピーする
2. Notionでデータベースを作成したい親ページを開き、右上「…」→「接続を追加」で①のインテグレーションを接続する
3. そのページのURLをアプリ内の「親ページのURL」欄に貼り付け、トークンと合わせて「データベースを自動作成して連携」を押す

これで以下の6つのデータベースが自動的に作成され、アプリから使えるようになります。

| データベース | 主なプロパティ |
| --- | --- |
| 説教 | タイトル / 聖書箇所 / 日付 / ステータス / 本文 / 主題 |
| 教会員 | 氏名 / フリガナ / 家族 / 連絡先 / 洗礼日 / 会員種別 / 備考 |
| 牧会記録 | タイトル / 対象者 / 日付 / 種別 / 内容 / 次回フォロー予定 / 完了 |
| 行事 | タイトル / 種別 / 日時 / 場所 / 奉仕者 / メモ |
| 祈祷課題 | タイトル / 内容 / カテゴリ / ステータス / 日付 |
| 献金記録 | タイトル / 日付 / 種別 / 金額 / メモ |

既にNotion側にデータベースがある場合は、セットアップ画面の「既存のデータベースIDを手動で入力する」から個別にIDを貼り付けることもできます。

設定内容は「ホーム」右上の歯車アイコンからいつでも確認・再設定・解除できます。
